# 07 - Calidad de Interfaz y Diseño Previo

## 1. Obligatoriedad de Brainstorm
ANTES de escribir código para una pantalla o módulo nuevo **DEBES** usar la skill `lluvia-ideas` y obtener la aprobación del diseño. No saltes directamente a programar sin pensar la estructura.

## 2. Componentes Frontend (Shadcn UI)
Está **ESTRICTAMENTE PROHIBIDO** crear componentes de interfaz base desde cero si existen en la librería estándar.
- **DEBES** usar siempre el CLI para instalar componentes: `npx shadcn@latest add <nombre-componente>` (dentro de `frontend/`).
- Construye las interfaces apoyándote completamente en estos componentes.

## 3. Estilo Profesional por Defecto
- El diseño visual **NO DEBE SER BÁSICO**. Estilo profesional, minimalista y pulido (márgenes en múltiplos de 4px, paletas armoniosas, tipografías modernas).
- Acabado premium y animaciones sutiles (transiciones de Tailwind, 150–250 ms), siguiendo la skill `diseno-interfaz`.
